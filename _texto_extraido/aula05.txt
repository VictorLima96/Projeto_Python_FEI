Análise do código
x é um contador
Um contador é uma variável que conta o número de ocorrências de
um evento: nesse caso, o número de repetições
Obs: Um acumulador é uma variável que acumula um valor a cada
repetição

Comando break
Porém, mesmo quando utilizamos um while infinito, é possível que
em determinadas situações o programa precise sair do laço de
repetição
Esta interrupção pode ser alcançada com o comando break
O comando break pode ser utilizado para interromper o while,
independentemente da condição
